# 午后三点 · 品牌项目笔记

> **品牌名**：午后三点
> **品牌定位**：帮你在胡同里多待五分钟。
> **核心理念**：通过视觉 + 触觉（交互）+ 听觉，让人真正"感受"胡同，而不是"看"胡同。

> **为什么是「午后三点」？**
> 这是一天里胡同最"慢"的时刻——午睡刚醒，太阳偏西，槐树影子拉长，
> 大爷坐在门墩上发呆，猫趴在墙头，鸽哨声格外清晰。
> 这是最容易"多待五分钟"的时候，因为这一刻，时间好像停了。

---

## 版本规划

### v1 — 单页滚动体验（当前）
- 4 个交互场景，每个占一屏
- 纯 HTML/CSS/JS，零依赖
- Web Audio API 生成音景
- 鼠标交互（悬停/点击/跟随）

### v2 — 待定
- 更丰富的动画和过渡
- 移动端触控优化
- 更多互动场景

### v3 — 待定
- 真实胡同录音替换合成音
- 更精细的插画/视觉

## 交互场景设计

| # | 场景 | 视觉 | 交互 | 声音 | 状态 |
|---|------|------|------|------|------|
| 1 | **鸽哨** | 鸽群在天际盘旋，远山或屋檐剪影 | 鼠标移动控制鸽群飞行轨迹 | 鸽哨声（频率 sweep） | ✅ 完成 |
| 2 | **槐荫** | 槐树光影婆娑，树影在地上晃动 | 滚动/鼠标产生"风"，树叶摇动 | 风吹树叶 + 远处蝉鸣 | ✅ 完成 |
| 3 | **推门** | 一扇老木门，门环、门缝透光 | 点击/拖动开门，窥见院内 | 门轴吱呀声 | ✅ 完成 |
| 4 | **门墩** | 门墩石鼓，苔藓和磨损痕迹 | 鼠标抚摸浮现纹理和故事文字 | 远处孩童嬉笑声、鸽哨渐远 | ✅ 完成 |

## 音景设计（Web Audio API）

| 声音 | 实现方式 |
|------|----------|
| 鸽哨 | 正弦波 + 频率 sweep + 颤音调制 |
| 风吹树叶 | 白噪声 → 带通滤波器 + LFO 调制 |
| 蝉鸣 | 双高频振荡器 + 颤音 |
| 门轴声 | 低频噪声 + 缓包络 |
| 胡同氛围 | 混合低频 + 偶发高频细节 |
