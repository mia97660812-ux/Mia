# 宠物社交 App — UI/UX 设计方案

## 产品定位

> **产品名建议**：PawPal / 爪爪 / 宠屿
> **Slogan**：让毛孩子的社交更简单
> **目标用户**：18-35 岁宠物主，以猫狗为主，辐射异宠

---

## 一、设计系统

### 色彩体系

| 角色 | 色值 | 用途 |
|------|------|------|
| 品牌主色 | `#FF7D6B` 珊瑚橙 | 按钮、Tab 选中、关键交互 |
| 品牌辅色 | `#FFD166` 暖黄 | 标签、提醒、勋章 |
| 背景 | `#F8F9FA` 极浅灰 | 页面背景 |
| 卡片 | `#FFFFFF` 白 | Feed 卡片、弹窗 |
| 文字主要 | `#1A1A2E` 深蓝黑 | 标题 |
| 文字次要 | `#6C757D` 中灰 | 副文本 |
| 点缀 | `#4ECDC4` 薄荷绿 | 在线状态、成功反馈 |

### 字体

- **标题/数字**：SF Pro Display / PingFang SC Semibold
- **正文**：SF Pro Text / PingFang SC Regular
- **圆角体系**：12px（卡片）/ 20px（按钮）/ 28px（弹窗）

### Icon 风格

- 线性 icon，2px stroke，圆角端点
- 宠物相关用自定义图形（爪印、骨头、鱼）

## 三、关键交互微动效

| 交互 | 动效 | 时长 |
|------|------|------|
| Feed 点赞 | 爱心缩放 + 粒子散开 | 0.3s |
| 切换 Tab | 柔和 Slide | 0.25s |
| 下拉刷新 | 猫爪动画旋转 | — |
| 附近宠物气泡 | 呼吸式脉动 | 2s loop |
| 发送"撸一下" | 猫爪轻拍动画 | 0.4s |
